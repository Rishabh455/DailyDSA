## Java Spring Boot & Microservices — Master Annotation Reference (Part 1: #1–50)

---

### 🔷 Category 1: Core Java & Jakarta EE

| # | Annotation | Framework / Module | Core Purpose & When to Use | Code Example |
|---|---|---|---|---|
| 1 | `@Override` | Java Lang (`java.lang`) | Signals that a method is overriding a superclass or interface method. Compiler catches typos in method signatures. Use on every `@Override` candidate — it's a safety contract. | `@Override`<br>`public String toString() {`<br>`  return "User[id=" + id + "]";`<br>`}` |
| 2 | `@Deprecated` | Java Lang (`java.lang`) | Marks a type, method, or field as obsolete. IDE/compiler issues warnings on usage. Use `@Deprecated(since="3.1", forRemoval=true)` in modern Java to specify replacement timeline. | `@Deprecated(since = "2.0", forRemoval = true)`<br>`public String getFullName() {`<br>`  return firstName + " " + lastName; // use getName()`<br>`}` |
| 3 | `@FunctionalInterface` | Java Lang (`java.lang`) | Marks an interface as a SAM (Single Abstract Method) type, enabling lambda usage. Compiler enforces the one-method contract. Essential when designing custom functional types. | `@FunctionalInterface`<br>`public interface OrderProcessor {`<br>`  void process(Order order);`<br>`}` <br>// Usage: `OrderProcessor op = o -> log(o);` |
| 4 | `@SuppressWarnings` | Java Lang (`java.lang`) | Suppresses specific compiler warnings (e.g., `"unchecked"`, `"rawtypes"`, `"deprecation"`). Use narrowly — never suppress `"all"` globally in production code. | `@SuppressWarnings("unchecked")`<br>`public List<User> fetchUsers() {`<br>`  return (List<User>) legacyDao.getAll();`<br>`}` |
| 5 | `@SafeVarargs` | Java Lang (`java.lang`) | Suppresses heap pollution warnings on varargs methods with generic types. Apply only to `final`, `static`, or `private` methods where varargs usage is genuinely safe. | `@SafeVarargs`<br>`public static <T> List<T> listOf(T... items) {`<br>`  return Arrays.asList(items);`<br>`}` |
| 6 | `@NotNull` | Jakarta Validation (`jakarta.validation.constraints`) | Field/parameter must not be null. Works with `@Valid`/`@Validated`. Does not reject empty strings — pair with `@NotBlank` for strings. | `public class CreateUserRequest {`<br>`  @NotNull(message = "Role is mandatory")`<br>`  private Role role;`<br>`}` |
| 7 | `@NotBlank` | Jakarta Validation | Field must not be null and must contain at least one non-whitespace character. The strongest constraint for text fields. Prefer over `@NotNull` + `@NotEmpty` for Strings. | `public class LoginRequest {`<br>`  @NotBlank(message = "Username required")`<br>`  private String username;`<br>`  @NotBlank`<br>`  private String password;`<br>`}` |
| 8 | `@NotEmpty` | Jakarta Validation | Collection, array, map, or String must not be null and not empty. Use on `List`/`Set` fields; `@NotBlank` is preferred for Strings. | `public class OrderRequest {`<br>`  @NotEmpty(message = "At least one item required")`<br>`  private List<OrderItem> items;`<br>`}` |
| 9 | `@Size` | Jakarta Validation | Validates that a String length or Collection size is within `min`/`max` bounds. Use for username length limits, page size constraints, etc. | `@Size(min = 8, max = 64,`<br>`  message = "Password must be 8–64 chars")`<br>`private String password;` |
| 10 | `@Min` / `@Max` | Jakarta Validation | Validates that a numeric value is ≥ min or ≤ max. Works on `int`, `long`, `BigDecimal`, etc. Essential for financial amounts and pagination params. | `@Min(value = 1, message = "Page must be >= 1")`<br>`@Max(value = 100, message = "Max 100 per page")`<br>`private int pageSize;` |
| 11 | `@Pattern` | Jakarta Validation | Validates a String against a `regexp`. Use for phone numbers, zip codes, custom codes. Regex is applied via `java.util.regex`. | `@Pattern(`<br>`  regexp = "^[6-9]\\d{9}$",`<br>`  message = "Invalid Indian mobile number")`<br>`private String mobile;` |
| 12 | `@Email` | Jakarta Validation | Validates that a String is a well-formed email address. Backed by RFC-compliant regex internally. Use on any email field in request DTOs. | `public class RegistrationRequest {`<br>`  @Email(message = "Invalid email format")`<br>`  @NotBlank`<br>`  private String email;`<br>`}` |
| 13 | `@Valid` | Jakarta Validation / Spring | Triggers cascaded validation on a method parameter, return value, or nested object. Applied at Controller layer to validate `@RequestBody` DTOs. | `@PostMapping("/users")`<br>`public ResponseEntity<Void> create(`<br>`  @Valid @RequestBody CreateUserRequest req) {`<br>`  userService.create(req);`<br>`  return ResponseEntity.status(201).build();`<br>`}` |
| 14 | `@Validated` | Spring Validation (`org.springframework.validation.annotation`) | Spring's variant of `@Valid`; supports validation groups and works on `@Service`-level methods too (via AOP proxy). Use `@Validated` at class level + `@Valid` on params for group-based validation. | `@Service`<br>`@Validated`<br>`public class PaymentService {`<br>`  public void charge(`<br>`    @Valid @NotNull PaymentRequest req) {`<br>`    // validated before method body runs`<br>`  }`<br>`}` |
| 15 | `@Constraint` | Jakarta Validation | Meta-annotation for defining **custom constraint annotations**. Used alongside a `ConstraintValidator` implementation. Necessary when built-in constraints aren't enough (e.g., `@ValidGSTIN`). | `@Target(FIELD) @Retention(RUNTIME)`<br>`@Constraint(validatedBy = GstinValidator.class)`<br>`public @interface ValidGSTIN {`<br>`  String message() default "Invalid GSTIN";`<br>`  Class<?>[] groups() default {};`<br>`  Class<? extends Payload>[] payload() default {};`<br>`}` |

### 🔷 Category 1 (continued): JPA / Hibernate

| # | Annotation | Framework / Module | Core Purpose & When to Use | Code Example |
|---|---|---|---|---|
| 16 | `@Entity` | JPA (`jakarta.persistence`) | Marks a POJO as a JPA-managed entity mapped to a DB table. Required on every Hibernate domain class. Class must have a no-arg constructor and an `@Id` field. | `@Entity`<br>`public class Employee {`<br>`  @Id`<br>`  @GeneratedValue(strategy = GenerationType.IDENTITY)`<br>`  private Long id;`<br>`  private String name;`<br>`}` |
| 17 | `@Table` | JPA | Specifies the DB table name, schema, and unique constraints for an entity. Use when the table name differs from the class name or multi-schema setups. | `@Entity`<br>`@Table(name = "tbl_employees",`<br>`  schema = "hr",`<br>`  uniqueConstraints = @UniqueConstraint(columnNames = "email"))`<br>`public class Employee { ... }` |
| 18 | `@Id` | JPA | Designates the primary key field. Every `@Entity` must have exactly one `@Id`. Supports `Long`, `UUID`, `String`, composite keys via `@EmbeddedId`. | `@Entity`<br>`public class Product {`<br>`  @Id`<br>`  private UUID productId;`<br>`}` |
| 19 | `@GeneratedValue` | JPA | Specifies PK generation strategy: `IDENTITY` (DB auto-increment), `SEQUENCE` (DB sequence), `TABLE` (portable), `UUID` (Java 17+). Use `IDENTITY` for MySQL, `SEQUENCE` for PostgreSQL. | `@Id`<br>`@GeneratedValue(strategy = GenerationType.SEQUENCE,`<br>`  generator = "emp_seq")`<br>`@SequenceGenerator(name = "emp_seq",`<br>`  sequenceName = "employee_sequence", allocationSize = 50)`<br>`private Long id;` |
| 20 | `@Column` | JPA | Maps a field to a specific DB column. Controls name, nullability, length, precision, scale, updatability. Without it, Hibernate infers column name from field name. | `@Column(name = "email_address",`<br>`  nullable = false, length = 255, unique = true)`<br>`private String email;`<br><br>`@Column(precision = 18, scale = 4)`<br>`private BigDecimal salary;` |
| 21 | `@OneToMany` | JPA | One entity has a collection of another. Typically the **"one" side** of a bidirectional relationship. Use `mappedBy` on this side to avoid a join table and mark it as inverse. Lazy by default — keep it that way. | `@Entity`<br>`public class Department {`<br>`  @OneToMany(mappedBy = "department",`<br>`    cascade = CascadeType.ALL,`<br>`    fetch = FetchType.LAZY)`<br>`  private List<Employee> employees = new ArrayList<>();`<br>`}` |
| 22 | `@ManyToOne` | JPA | Many entities reference one entity. The **owning side** — holds the foreign key column. Always `EAGER` by default — change to `LAZY` explicitly to avoid N+1 issues. | `@Entity`<br>`public class Employee {`<br>`  @ManyToOne(fetch = FetchType.LAZY)`<br>`  @JoinColumn(name = "dept_id",`<br>`    nullable = false)`<br>`  private Department department;`<br>`}` |
| 23 | `@ManyToMany` | JPA | Both sides can have multiple of the other. Hibernate creates a join table by default. Use `@JoinTable` to control join table name/columns. Prefer modeling the join entity explicitly for extra attributes. | `@ManyToMany`<br>`@JoinTable(name = "employee_projects",`<br>`  joinColumns = @JoinColumn(name = "emp_id"),`<br>`  inverseJoinColumns = @JoinColumn(name = "proj_id"))`<br>`private Set<Project> projects = new HashSet<>();` |
| 24 | `@JoinColumn` | JPA | Specifies the FK column used in `@ManyToOne` / `@OneToOne` relationships. Without it, Hibernate generates a column name from field names. Use it to maintain explicit control over DDL. | `@ManyToOne(fetch = FetchType.LAZY)`<br>`@JoinColumn(`<br>`  name = "manager_id",`<br>`  referencedColumnName = "id",`<br>`  nullable = true)`<br>`private Employee manager;` |
| 25 | `@Transient` | JPA | Excludes a field from persistence. The field exists in Java but has no corresponding DB column. Use for computed/derived fields or temporary state in entities. | `@Entity`<br>`public class Order {`<br>`  private BigDecimal basePrice;`<br>`  private BigDecimal taxRate;`<br>`  @Transient`<br>`  public BigDecimal getTotalPrice() {`<br>`    return basePrice.multiply(BigDecimal.ONE.add(taxRate));`<br>`  }`<br>`}` |
| 26 | `@Embeddable` / `@Embedded` | JPA | `@Embeddable` marks a value type class with no identity of its own (e.g., `Address`). `@Embedded` inlines it into the owning entity's table. Eliminates unnecessary join tables for value objects. | `@Embeddable`<br>`public class Address {`<br>`  private String street;`<br>`  private String city;`<br>`  private String pinCode;`<br>`}`<br><br>`@Entity`<br>`public class Employee {`<br>`  @Embedded`<br>`  private Address address;`<br>`}` |
| 27 | `@Enumerated` | JPA | Maps a Java `enum` to a DB column. `EnumType.STRING` stores enum name (preferred — readable, refactor-safe). `EnumType.ORDINAL` stores index — **avoid** (breaks on reorder). | `@Enumerated(EnumType.STRING)`<br>`@Column(name = "status", length = 20)`<br>`private OrderStatus status;`<br>// Stores "PENDING", "SHIPPED", not 0, 1 |
| 28 | `@Lob` | JPA | Maps a field to a Large Object column (`CLOB`/`BLOB`). Use for large text (HTML, XML, JSON) or binary data (images, PDFs). Combined with `@Column(columnDefinition = "TEXT")` for portability. | `@Lob`<br>`@Column(columnDefinition = "TEXT")`<br>`private String htmlContent;`<br><br>`@Lob`<br>`private byte[] documentBytes;` |
| 29 | `@Version` | JPA | Enables **optimistic locking**. Hibernate auto-increments the version field on every update and throws `OptimisticLockException` on concurrent modification. Essential in high-concurrency microservices. | `@Entity`<br>`public class Account {`<br>`  @Id private Long id;`<br>`  private BigDecimal balance;`<br>`  @Version`<br>`  private Long version; // auto-managed by Hibernate`<br>`}` |
| 30 | `@NamedQuery` | JPA | Defines a pre-compiled JPQL query at the entity level. Parsed at startup (fail-fast). Use for frequently executed, static queries — better than ad-hoc JPQL strings at runtime. | `@Entity`<br>`@NamedQuery(`<br>`  name = "Employee.findByDept",`<br>`  query = "SELECT e FROM Employee e`<br>`           WHERE e.department.id = :deptId`<br>`           AND e.active = true"`<br>`)`<br>`public class Employee { ... }` |

### 🔷 Category 2: Spring Framework Core — IoC, DI, Configuration

| # | Annotation | Framework / Module | Core Purpose & When to Use | Code Example |
|---|---|---|---|---|
| 31 | `@Component` | Spring Core (`org.springframework.stereotype`) | Generic stereotype for any Spring-managed bean. Base annotation for `@Service`, `@Repository`, `@Controller`. Use directly for utility classes, helper beans not fitting other stereotypes. | `@Component`<br>`public class JwtTokenUtil {`<br>`  public String generateToken(String username) {`<br>`    return Jwts.builder().setSubject(username)`<br>`             .signWith(secretKey).compact();`<br>`  }`<br>`}` |
| 32 | `@Service` | Spring Core | Stereotype for business logic layer. Semantically equivalent to `@Component` but communicates intent. Spring AOP transaction advice applies here. Always use over raw `@Component` in service classes. | `@Service`<br>`@RequiredArgsConstructor`<br>`public class UserService {`<br>`  private final UserRepository userRepository;`<br>`  public User findById(Long id) {`<br>`    return userRepository.findById(id)`<br>`      .orElseThrow(() -> new UserNotFoundException(id));`<br>`  }`<br>`}` |
| 33 | `@Repository` | Spring Core | Stereotype for data access layer. Enables Spring's persistence exception translation — DB-specific exceptions (`SQLException`) get translated to `DataAccessException`. Use on all DAO/Repository classes. | `@Repository`<br>`public interface EmployeeRepository`<br>`  extends JpaRepository<Employee, Long> {`<br>`  Optional<Employee> findByEmail(String email);`<br>`  @Query("SELECT e FROM Employee e WHERE e.dept.id = :id")`<br>`  List<Employee> findByDeptId(@Param("id") Long id);`<br>`}` |
| 34 | `@Configuration` | Spring Core | Marks a class as a **source of bean definitions**. Methods annotated with `@Bean` inside `@Configuration` classes are proxied by CGLIB — guaranteeing singleton behaviour even with inter-bean method calls. | `@Configuration`<br>`public class KafkaConfig {`<br>`  @Bean`<br>`  public ProducerFactory<String, Object> producerFactory() {`<br>`    Map<String, Object> props = new HashMap<>();`<br>`    props.put(BOOTSTRAP_SERVERS_CONFIG, "localhost:9092");`<br>`    return new DefaultKafkaProducerFactory<>(props);`<br>`  }`<br>`}` |
| 35 | `@Bean` | Spring Core | Declares a method return value as a Spring-managed bean. Used inside `@Configuration` classes. Name defaults to method name. Use when third-party class instantiation needs custom logic (e.g., `RestTemplate`, `ObjectMapper`). | `@Configuration`<br>`public class AppConfig {`<br>`  @Bean`<br>`  @Primary`<br>`  public ObjectMapper objectMapper() {`<br>`    return new ObjectMapper()`<br>`      .registerModule(new JavaTimeModule())`<br>`      .disable(WRITE_DATES_AS_TIMESTAMPS);`<br>`  }`<br>`}` |
| 36 | `@Autowired` | Spring Core | Injects Spring beans by type. Works on constructors, setters, and fields. **Constructor injection is preferred** (immutable, testable). Field injection is convenient but hides dependencies — avoid in production code. | `@Service`<br>`public class OrderService {`<br>`  private final OrderRepository orderRepo;`<br>`  private final PaymentClient paymentClient;`<br>`  @Autowired // optional on single constructor`<br>`  public OrderService(OrderRepository r, PaymentClient p) {`<br>`    this.orderRepo = r;`<br>`    this.paymentClient = p;`<br>`  }`<br>`}` |
| 37 | `@Qualifier` | Spring Core | Disambiguates when multiple beans of the same type exist. Combine with `@Autowired`. Define the qualifier name with `@Qualifier` on the `@Bean` declaration and match on injection site. | `@Bean @Qualifier("primaryDS")`<br>`public DataSource primaryDataSource() { ... }`<br><br>`@Bean @Qualifier("auditDS")`<br>`public DataSource auditDataSource() { ... }`<br><br>`@Autowired @Qualifier("auditDS")`<br>`private DataSource auditDS;` |
| 38 | `@Primary` | Spring Core | Marks a bean as the **default candidate** for autowiring when multiple beans of the same type exist. Eliminates the need for `@Qualifier` at every injection site. Use alongside `@Qualifier` for explicit overrides. | `@Bean`<br>`@Primary`<br>`public CacheManager redisCacheManager(RedisConnectionFactory f) {`<br>`  return RedisCacheManager.builder(f).build();`<br>`}`<br><br>`@Bean`<br>`public CacheManager caffeineCacheManager() { ... }` |
| 39 | `@Value` | Spring Core | Injects values from `application.properties`, environment variables, or SpEL expressions directly into fields or constructor params. Supports default values via `:` syntax. | `@Service`<br>`public class NotificationService {`<br>`  @Value("${notification.email.from:noreply@app.com}")`<br>`  private String fromEmail;`<br><br>`  @Value("${max.retry.count:3}")`<br>`  private int maxRetry;`<br>`}` |
| 40 | `@Scope` | Spring Core | Controls bean lifecycle: `singleton` (default), `prototype` (new per injection), `request`, `session` (web scopes). Use `prototype` for stateful helper beans. Use `request`/`session` in web apps for per-request state. | `@Component`<br>`@Scope(value = ConfigurableBeanFactory.SCOPE_PROTOTYPE)`<br>`public class ReportBuilder {`<br>`  private final List<ReportSection> sections = new ArrayList<>();`<br>`  // new instance per injection point`<br>`}` |
| 41 | `@Lazy` | Spring Core | Defers bean initialization until first use instead of at startup. Use to break circular dependencies or speed up startup time for rarely-used, expensive beans. | `@Service`<br>`@Lazy`<br>`public class HeavyAnalyticsService {`<br>`  public HeavyAnalyticsService() {`<br>`    // expensive init — skipped until first call`<br>`  }`<br>`}` |
| 42 | `@Profile` | Spring Core | Activates a bean or configuration only when specific Spring profiles are active. Use for environment-specific wiring: `dev`, `prod`, `test`. Set active profile via `spring.profiles.active`. | `@Configuration`<br>`@Profile("dev")`<br>`public class DevEmailConfig {`<br>`  @Bean`<br>`  public JavaMailSender mailSender() {`<br>`    return new FakeMailSender(); // no real emails in dev`<br>`  }`<br>`}` |
| 43 | `@Conditional` | Spring Core | Generic meta-annotation for conditional bean registration. The base of all `@ConditionalOn*` annotations. Implement `Condition` interface to write custom matching logic. | `public class OnLinuxCondition implements Condition {`<br>`  @Override`<br>`  public boolean matches(ConditionContext ctx, AnnotatedTypeMetadata m) {`<br>`    return ctx.getEnvironment().getProperty("os.name","").contains("Linux");`<br>`  }`<br>`}`<br>`@Bean @Conditional(OnLinuxCondition.class)`<br>`public FileWatcher linuxWatcher() { return new InotifyWatcher(); }` |
| 44 | `@PropertySource` | Spring Core | Loads additional `.properties` files into the `Environment`. Use in `@Configuration` classes when you need multiple property files beyond `application.properties`. Supports classpath and file system paths. | `@Configuration`<br>`@PropertySource("classpath:kafka.properties")`<br>`@PropertySource("classpath:redis.properties")`<br>`public class InfraConfig {`<br>`  @Value("${kafka.bootstrap.servers}")`<br>`  private String kafkaServers;`<br>`}` |

### 🔷 Category 2 (continued): Spring AOP

| # | Annotation | Framework / Module | Core Purpose & When to Use | Code Example |
|---|---|---|---|---|
| 45 | `@Aspect` | Spring AOP (`org.aspectj.lang.annotation`) | Marks a class as an Aspect — a container for cross-cutting concerns (logging, auditing, performance, security). Requires `@EnableAspectJAutoProxy` (auto-enabled in Spring Boot). | `@Aspect`<br>`@Component`<br>`@Slf4j`<br>`public class ExecutionTimeAspect {`<br>`  @Around("@annotation(com.app.Timed)")`<br>`  public Object time(ProceedingJoinPoint pjp) throws Throwable {`<br>`    long start = System.currentTimeMillis();`<br>`    Object result = pjp.proceed();`<br>`    log.info("{} took {}ms", pjp.getSignature(), System.currentTimeMillis() - start);`<br>`    return result;`<br>`  }`<br>`}` |
| 46 | `@Before` | Spring AOP | Advice that runs **before** the matched join point. Does not control method execution — it always proceeds. Use for pre-execution logging, audit trail entry, permission checks. | `@Aspect @Component`<br>`public class AuditAspect {`<br>`  @Before("execution(* com.app.service.*.*(..)) && @annotation(auditable)")`<br>`  public void logBefore(JoinPoint jp, Auditable auditable) {`<br>`    auditLog.record(jp.getSignature().getName(),`<br>`      SecurityContextHolder.getContext().getAuthentication().getName());`<br>`  }`<br>`}` |
| 47 | `@After` | Spring AOP | Advice that runs **after** the join point, regardless of outcome (finally-block semantics). Use for resource cleanup, lock release. For outcome-specific logic, prefer `@AfterReturning` or `@AfterThrowing`. | `@After("execution(* com.app.service.CacheService.evict(..))")`<br>`public void afterEviction(JoinPoint jp) {`<br>`  metricsService.incrementCacheEviction(`<br>`    jp.getSignature().toShortString());`<br>`}` |
| 48 | `@Around` | Spring AOP | Most powerful advice — wraps the join point completely. Can inspect/modify args, suppress/replace the call, and handle exceptions. Use for retry logic, rate limiting, distributed tracing. **Must call `pjp.proceed()`** or the method won't execute. | `@Around("@annotation(RateLimit)")`<br>`public Object rateLimit(ProceedingJoinPoint pjp) throws Throwable {`<br>`  String key = pjp.getSignature().toString();`<br>`  if (rateLimiter.tryAcquire(key)) {`<br>`    return pjp.proceed();`<br>`  }`<br>`  throw new RateLimitExceededException("Rate limit hit for: " + key);`<br>`}` |
| 49 | `@Pointcut` | Spring AOP | Defines a **reusable pointcut expression** that can be referenced by multiple advice methods. Eliminates duplication of complex execution expressions across an aspect class. | `@Aspect @Component`<br>`public class ServiceAspect {`<br>`  @Pointcut("execution(* com.app.service..*(..))")`<br>`  public void serviceLayer() {}`<br><br>`  @Before("serviceLayer()")`<br>`  public void log(JoinPoint jp) {`<br>`    log.info("Entering: {}", jp.getSignature());`<br>`  }`<br>`}` |
| 50 | `@AfterReturning` | Spring AOP | Advice that runs **only when the method returns successfully** (not on exception). Binding `returning` param lets you inspect the return value. Use for response enrichment, audit on success. | `@AfterReturning(`<br>`  pointcut = "execution(* com.app.service.OrderService.placeOrder(..))",`<br>`  returning = "order")`<br>`public void onOrderPlaced(JoinPoint jp, Order order) {`<br>`  notificationService.sendConfirmation(order.getCustomerEmail());`<br>`  inventoryService.deduct(order.getItems());`<br>`}` |

### 🔷 Category 3: Spring Boot — Auto-Configuration & Startup

| # | Annotation | Framework / Module | Core Purpose & When to Use | Code Example |
|---|---|---|---|---|
| 51 | `@SpringBootApplication` | Spring Boot (`org.springframework.boot.autoconfigure`) | Composite of `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`. Entry point of every Spring Boot app. Scan base package defaults to the class's package — always place this in the **root package**. | `@SpringBootApplication`<br>`public class OrderServiceApplication {`<br>`  public static void main(String[] args) {`<br>`    SpringApplication app = new SpringApplication(OrderServiceApplication.class);`<br>`    app.setDefaultProperties(Map.of("server.port","8081"));`<br>`    app.run(args);`<br>`  }`<br>`}` |
| 52 | `@EnableAutoConfiguration` | Spring Boot | Instructs Spring Boot to apply auto-configuration based on JARs on the classpath (reads `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`). Use `exclude` to suppress unwanted configs (e.g., `DataSourceAutoConfiguration` in non-DB services). | `@SpringBootApplication(`<br>`  exclude = {`<br>`    DataSourceAutoConfiguration.class,`<br>`    SecurityAutoConfiguration.class`<br>`  }`<br>`)`<br>`public class NotificationServiceApp { ... }` |
| 53 | `@ComponentScan` | Spring Boot / Spring Core | Tells Spring where to scan for stereotype-annotated classes. Customize `basePackages` when you have a multi-module Maven project with beans in different root packages. | `@SpringBootApplication`<br>`@ComponentScan(basePackages = {`<br>`  "com.company.orderservice",`<br>`  "com.company.common.security",`<br>`  "com.company.common.audit"`<br>`})`<br>`public class OrderServiceApp { ... }` |
| 54 | `@ConfigurationProperties` | Spring Boot | Binds a **group of related properties** from `application.yml/properties` to a strongly-typed POJO. Far superior to multiple `@Value` annotations. Supports nested objects, lists, maps, and JSR-303 validation via `@Validated`. | `@Component`<br>`@ConfigurationProperties(prefix = "app.kafka")`<br>`@Validated`<br>`@Data`<br>`public class KafkaProperties {`<br>`  @NotBlank private String bootstrapServers;`<br>`  @Min(1) private int retries = 3;`<br>`  private Map<String, String> topics = new HashMap<>();`<br>`}` |
| 55 | `@ConditionalOnProperty` | Spring Boot | Registers a bean **only if** a specific property exists and/or has a given value. Essential for feature flags, toggling integrations (e.g., enable Kafka only if `app.kafka.enabled=true`). | `@Configuration`<br>`@ConditionalOnProperty(`<br>`  prefix = "app.feature",`<br>`  name = "kafka-enabled",`<br>`  havingValue = "true",`<br>`  matchIfMissing = false)`<br>`public class KafkaProducerConfig {`<br>`  @Bean`<br>`  public KafkaTemplate<String, Object> kafkaTemplate() { ... }`<br>`}` |
| 56 | `@ConditionalOnMissingBean` | Spring Boot | Registers a bean **only if no bean of that type already exists** in the context. The backbone of Spring Boot's auto-configuration — lets users override defaults simply by declaring their own bean. | `@Bean`<br>`@ConditionalOnMissingBean(ObjectMapper.class)`<br>`public ObjectMapper defaultObjectMapper() {`<br>`  // used only if app hasn't declared its own ObjectMapper`<br>`  return new ObjectMapper()`<br>`    .registerModule(new JavaTimeModule());`<br>`}` |
| 57 | `@ConditionalOnClass` | Spring Boot | Activates a configuration only if a **specific class is present on the classpath**.
